# BorrowCircle

**A Campus Item Lending Mobile Application**

BorrowCircle is a mobile app designed for university students to lend and borrow academic and project-related items in a structured and accountable way.

---

## About the Project

Students often need items like calculators, textbooks, lab equipment, or sports gear for a short time but do not want to buy them permanently. Currently, they rely on WhatsApp groups or personal contacts, which lack tracking and accountability.

**BorrowCircle** solves this problem by providing:

- Peer-to-Peer lending (student to student)
- Peer-to-Group lending (e.g. IoT Club, Robotics Club)
- Full lending workflow: Request → Approve → Handover → Return → Review
- QR Code / One-time code for secure handover
- Dashboard for active loans and overdue items

---

## Key Features

- User registration & login (university email)
- List items (Individual or Group)
- Search & filter available items
- Send borrow requests for specific dates
- Approve / Reject requests
- QR Code or One-time code handover confirmation
- Return confirmation
- Leave reviews and ratings
- Active Loans / Dashboard
- My Requests & My Groups
